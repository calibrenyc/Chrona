## Fixed

- Prioritized AnkerGames and Online-Fix in game link search. AnkerGames links are generated from game titles when automated site search is blocked; Online-Fix results appear only when a matching game page is found.
- Restored the visible embedded browser toolbar and kept it below the Chrona title bar.
- Added a Downloads page to the sidebar. When a transfer starts, Chrona closes the embedded browser, opens Downloads, and shows a progress dialog with a Minimize button. Progress and download history remain on the Downloads page.

### Installing

Install **ChronaSetup-1.2.8.exe** over the existing copy. The installer preserves your game library and settings.
